# Econexa

O **Econexa** é uma plataforma educativa voltada para **educação ambiental, reciclagem e preservação da natureza**. O projeto foi desenvolvido com o objetivo de tornar informações sobre sustentabilidade mais acessíveis, interativas e fáceis de entender.

A proposta do Econexa é conectar tecnologia e meio ambiente em um único espaço, oferecendo recursos que ajudam o usuário a aprender sobre práticas sustentáveis e a tomar decisões mais conscientes no dia a dia.

## O que o Econexa faz?

O projeto reúne diferentes ferramentas e conteúdos relacionados ao meio ambiente, incluindo:

* **Econexa IA:** uma assistente virtual que ajuda o usuário a tirar dúvidas e aprender sobre sustentabilidade.
* **Descarte correto:** informações para ajudar a identificar a forma adequada de descartar diferentes tipos de resíduos.
* **Projeto Tamar:** uma área dedicada à preservação das tartarugas marinhas e à conscientização sobre a importância da proteção da vida marinha.
* **Compostagem:** informações sobre compostagem e reaproveitamento de resíduos orgânicos.
* **Formulário de contato:** permite que os usuários enviem mensagens e sugestões.
* **Conteúdo educativo:** informações e materiais relacionados à preservação ambiental e à sustentabilidade.

## Tecnologias utilizadas

O Econexa foi desenvolvido principalmente utilizando tecnologias da web:

* **HTML5:** utilizado para estruturar as páginas e os conteúdos do projeto.
* **CSS3:** utilizado para criar o design, a organização visual, as cores e a responsividade do site.
* **JavaScript:** utilizado para adicionar interatividade e funcionalidades ao projeto, incluindo recursos da assistente virtual e interação com os elementos das páginas.
* **JSON:** utilizado em arquivos de configuração, como o `manifest.json`, permitindo também a configuração do projeto como uma aplicação web progressiva (PWA).

## Progressive Web App

O Econexa possui recursos de **Progressive Web App (PWA)**, permitindo que o projeto tenha características semelhantes às de um aplicativo.

O projeto conta com:

* `manifest.json`
* Ícone de 192×192 pixels
* Ícone de 512×512 pixels
* Service Worker
* Configurações para instalação como aplicativo

## Objetivo do projeto

O principal objetivo do Econexa é mostrar como a tecnologia pode ser utilizada como uma ferramenta de **educação e conscientização ambiental**.

O projeto busca incentivar pequenas atitudes que podem contribuir para a preservação do meio ambiente, como realizar o descarte correto dos resíduos, reduzir desperdícios, reutilizar materiais e conhecer projetos de conservação da natureza.

## Projeto

O Econexa foi desenvolvido como um projeto tecnológico com foco em **sustentabilidade, educação ambiental e inovação**, unindo programação, inteligência artificial e informação em uma única plataforma.

> **Econexa: tecnologia conectando pessoas e planeta.**
